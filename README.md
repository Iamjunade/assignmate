# AssignMate

**The AssignMate Network - Students Helping Students**

We are a movement of students helping students. We believe that knowledge grows when shared, and no one should have to struggle alone.

## About

AssignMate is a comprehensive platform designed for Indian college students to connect, collaborate, and grow academically. Whether you need help with assignments, want to find study partners, or are looking for hackathon teammates, AssignMate brings together students from IITs to local colleges in a supportive community.

### Key Features

- **Academic Marketplace**: Post assignments and connect with verified student writers
- **Community Platform**: Share knowledge, find study groups, and collaborate on projects
- **Campus Connections**: Bridge the gap between institutions and build meaningful relationships
- **Real-time Chat**: Seamless communication for all your academic needs
- **AI-Powered Onboarding**: Personalized profiles to match you with the right people

### Our Values

- **Empathy First**: Understanding academic pressures with kindness and patience
- **Active Collaboration**: True learning through understanding, explaining, and discussing
- **Inclusive Growth**: Connecting talent from all institutions, from IITs to local colleges

## Tech Stack

- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS
- **Backend**: Firebase (Firestore, Auth, Storage), Supabase
- **AI**: Google Gemini for profile generation and verification
- **Deployment**: Vercel

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Set up environment variables (see .env.local.example)
4. Run development server: `npm run dev`
